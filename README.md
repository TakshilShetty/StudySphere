# StudySphere

## Smart Academic Notes Sharing Platform

StudySphere is a student-focused platform designed to make academic learning easier by bringing study materials together in one place. It helps students access, share, and organize notes and other learning resources, saving time and improving collaboration.

## Project Objectives

- Provide a centralized platform for academic study materials.
- Help students find notes and resources relevant to their subjects.
- Encourage students to share useful learning materials.
- Make academic resources easier to access and organize.
- Support collaborative learning among students.

## Features

- **Academic Resources:** Access study materials through a centralized platform.
- **Organized Content:** Keep learning resources structured and easy to find.
- **Student Collaboration:** Enable students to contribute and share academic materials.
- **User-Friendly Interface:** Provide a simple and accessible learning experience.

## Getting Started

### Prerequisites

- Git
- Node.js and npm

### 1. Clone the Repository

```bash
git clone https://github.com/TakshilShetty/StudySphere.git
cd StudySphere
```

### 2. Set Up the Backend

Navigate to the backend directory:

```bash
cd backend
npm install
```

Configure the required environment variables according to the backend configuration.

Start the backend using the script defined in its `package.json`. For example:

```bash
npm run dev
```

### 3. Run the Frontend

Open `frontend/public/index.html` in your browser, or use the development server configured for your project.

If the frontend communicates with the backend, ensure that the backend is running and the API URL is configured correctly.
